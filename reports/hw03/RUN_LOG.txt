Summary of what happened at each stage:

2026-09-19: Part 1 built - a FastAPI authentication router (auth.py) with
Home, Login, Dashboard, and Logout routes, using Starlette's
SessionMiddleware with a secure cookie (httponly, secure, samesite=lax
all confirmed present in the real captured Set-Cookie header) and a
server-side session revocation store (ACTIVE_SESSIONS) enabling genuine
logout invalidation and a 30-second idle timeout - both independently
verified via curl by replaying an old session cookie after logout (and
separately after idle expiry) and confirming /dashboard correctly
rejected it both times, redirecting to /login. The existing HW2 fixtures
CRUD board was moved from "/" to "/fixtures" to make room for the new
auth-aware home page. All four routes were restyled with the existing
vintage newspaper theme applied on top of Bootstrap's components
(navbar, cards, buttons, alerts, form controls).

2026-09-20: Part 2 built across four stages:
  (1) A domain corpus was assembled from 6 real, public, verified
      documents (AYSO Basic Soccer Rules, AYSO National Rules &
      Regulations, City of Las Vegas Youth Basketball Rules, Fort
      Collins Adult Volleyball Manual, USPL Twenty20 Cricket Rules, and
      Douglas County Parks & Recreation All-Sports Rules), totaling
      232,807 bytes (227.4 KB), exceeding the 200KB requirement. Each
      file's SHA-256 hash and byte size were computed and recorded in
      CORPUS_MANIFEST.json, with source URLs and access dates in
      SOURCES.md.
  (2) 5 domain questions were written and committed to questions.yaml,
      with expected answers and expected source files recorded BEFORE
      any retrieval code was run, per the assignment's requirement.
  (3) Three chunking pipelines (Token, Semantic, Sentence-window) were
      built using LlamaIndex, each indexed into its own in-memory
      SimpleVectorStore using the sentence-transformers/all-MiniLM-L6-v2
      embedding model. A shared retrieval-only function was run against
      all 3 techniques x 5 questions (15 total retrievals), printing and
      saving query embedding dimensions/values, store scores, cosine
      similarities, chunk lengths, and previews for every result.
  (4) A separate summary script recomputed the final comparison table
      (chunks, avg chunk length, top-1 cosine, mean@k cosine, recall@k,
      mean latency) from the saved raw data, and a specific confidently-
      scored recall miss (Semantic chunking, question q1) was traced and
      explained in METRICS.md.
